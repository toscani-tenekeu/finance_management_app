# Code de conduite

Soyez respectueux, précis et constructif. Le harcèlement, les attaques personnelles, la discrimination, la publication de données privées et les comportements malveillants ne sont pas acceptés.

Les signalements doivent être envoyés au mainteneur du dépôt avec les faits utiles. Les mainteneurs peuvent modifier ou supprimer un contenu, refuser une contribution ou suspendre un participant afin de protéger le projet et sa communauté.
