# Contribuer

1. Créez une branche depuis `master`.
2. Limitez la modification à un objectif clair.
3. Ajoutez ou adaptez les tests.
4. Exécutez `npm run check`.
5. Ouvrez une pull request avec le problème traité et les contrôles effectués.

Ne joignez jamais de base SQLite, backup, mot de passe ou donnée financière réelle.
